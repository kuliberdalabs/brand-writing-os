# Pakiet języka polskiego

Stosuj przy redagowaniu tekstu po polsku. Najpierw ustal sens i źródła twierdzeń.
Potem usuń pusty język, sprawdź kompozycję i dopracuj rytm.
To sygnały redakcyjne, nie zakaz każdego wystąpienia danej frazy.
Cytat źródłowy i świadomy wybór głosu mogą zostać.
Nie dopisuj liczby, cytatu, historii ani szczegółu, którego nie ma w materiale.

## Zdania, które udają zwrot akcji

| Sygnał | Przeredaguj tak |
| --- | --- |
| „To nie jest X. To Y.” | Zacznij od Y i wyjaśnij, co konkretnie z niego wynika. |
| „To nie X, lecz Y.” | Nazwij Y bez wstępnego zaprzeczenia. |
| „Nie chodzi o X, ale o Y.” | Napisz, kto robi Y albo jakie Y ma znaczenie w tej sytuacji. |
| „Nie tylko X, ale również Y.” | Wybierz istotniejszy skutek; drugi dodaj tylko, gdy wnosi nowy fakt. |
| „Nie X, tylko Y.” | Zastąp kontrast opisem działania lub wyniku Y. |
| Lustrzane pary „X robi A. Y robi B.” | Zostaw różnicę, która jest udokumentowana; przestań dopasowywać składnię. |
| Dwa kolejne posty otwarte antytezą | Zmień budowę jednego otwarcia, nie tylko rzeczowniki. |

Kontrast bywa potrzebny do wyjaśnienia realnego rozróżnienia.
Sprawdź, czy bez pierwszej, negującej połowy czytelnik straci informację.
Jeśli tak, zachowaj sens i opisz różnicę w naturalnym zdaniu.

**Przed:** „To nie jest kolejny kalendarz. To sposób na lepszą pracę.”

**Po:** „Recepcja wpisuje wizyty do kalendarza, a rano sprawdza w nim wolne terminy.”

Ten przykład jest wymyślony i pokazuje tylko zmianę składni.

## Negatywne wyliczenia i dramatyczne urywki

| Sygnał | Przeredaguj tak |
| --- | --- |
| „Nie X… Nie Y… Z.” | Nazwij Z od razu; X i Y zachowaj tylko jako potrzebne wykluczenia. |
| „Nie X. Nie Y. Z.” | Złącz fakty w zdanie, które pokazuje ich związek. |
| „X. Kropka.” | Usuń „Kropka” i pozwól konkretowi wybrzmieć. |
| „Jedno słowo: X.” | Wpisz X w zwykłe zdanie i wyjaśnij jego znaczenie. |
| „X. I tyle.” | Skończ po X albo dodaj potrzebne uzasadnienie. |
| Seria krótkich, odciętych zdań | Połącz te, które składają się na jedną myśl. |

Nie wygładzaj świadomego rytmu mechanicznie.
Jedno krótkie zdanie może pracować; seria identycznych pauz zwykle brzmi jak szablon.

## Retoryczne rozbiegi

| Sygnał | Przeredaguj tak |
| --- | --- |
| „A co gdyby…?” | Zacznij od realnej możliwości albo warunku. |
| „Pomyśl o tym:” | Podaj obserwację bez instrukcji dla czytelnika. |
| „I wiesz co?” | Przejdź do informacji, którą pytanie zapowiada. |
| Pytanie, po którym autor od razu odpowiada | Zapisz odpowiedź jako pierwsze zdanie, jeśli pytanie nie jest rzeczywistym problemem czytelnika. |
| „Przyjrzyjmy się temu bliżej” | Przejdź do konkretnego mechanizmu. |
| „W dalszej części omówimy” | Zacznij omawianie. |

Pytanie zostaw, gdy otwiera prawdziwą niewiadomą lub porządkuje wywód.
Nie używaj go wyłącznie jako trampoliny do gotowej odpowiedzi.

## Tempo całego tekstu

| Sygnał | Przeredaguj tak |
| --- | --- |
| Trzy podobne argumenty przed puentą | Zostaw argumenty niezbędne do wniosku; nie dopełniaj listy do trzech. |
| Trzeci punkt napisany tylko pod puentę | Usuń go albo przenieś jego fakt do wyjaśnienia. |
| „To domyka…” | Skończ na ostatnim konkretnym ustaleniu. |
| „Podsumowując…” | Usuń powtórzenie; dodaj tylko nowy wniosek, jeśli wynika z tekstu. |
| Cytat zawsze w ostatnim akapicie | Przenieś cytat tam, gdzie stanowi dowód lub wyjaśnia decyzję. |
| Krótki wstęp, równe akapity, krótka klamra (3/5/3) | Ułóż akapity według ciężaru informacji, zmień ich długość i usuń klamrę bez nowej treści. |
| Pięciowiersz z wstępem i podsumowaniem | Zacznij od właściwej myśli i zakończ, gdy została wyrażona. |
| Kilka tekstów o tym samym otwarciu lub finale | Zestaw je obok siebie i zmień konstrukcję jednego z nich. |

Lista pomaga czytelnikowi, kiedy elementy naprawdę trzeba rozdzielić.
Cytat może być zakończeniem, jeśli właśnie tam rozstrzyga sprawę.
Nie dodawaj cytatu ani puenty dla stałego miejsca w formacie.
Mieszaj budowę zdań, a nie tylko ich długość.
Po stwierdzeniu może przyjść wyjaśnienie, warunek lub przykład.
Krótki akapit ma mieć powód; dłuższy może być potrzebny do argumentu.

## Konkret zamiast absolutu

| Sygnał | Przeredaguj tak |
| --- | --- |
| „Każdy klient…” | Nazwij grupę klientów, której dotyczą źródła. |
| „Zawsze działa…” | Podaj warunki, w których działanie potwierdzono. |
| „Nigdy nie…” | Opisz konkretną sytuację, w której czegoś nie zaobserwowano. |
| „Nikt nie…” | Wskaż osoby lub zespół, o których naprawdę wiesz. |

Nie zastępuj absolutu słowem „często” bez podstawy.
Jeżeli źródło nie pozwala określić zakresu, ogranicz twierdzenie albo je usuń.

| roadmapa, roadmapy | plan, harmonogram, plan prac |
| stakeholderzy | zainteresowani, strony projektu, konkretne role |
| deliverables | wyniki pracy, materiały do oddania, konkretne pliki |
| leverage | wykorzystać, oprzeć na czymś |
| insight | obserwacja, wniosek, spostrzeżenie |
| feedback | uwagi, informacja zwrotna, ocena |
| game changer | opisz rzeczywistą zmianę i jej skutek |
| skalowalne | podaj, jak rośnie obciążenie i co nadal działa |
| innowacyjne | nazwij nową cechę albo usuń ocenę |
| nowoczesne technologie | nazwij technologię i jej zastosowanie |
| kompleksowe rozwiązania | nazwij usługę i zakres |
| holistyczne podejście | opisz powiązane działania |
| szeroki wachlarz usług | wymień te usługi, które mają znaczenie tutaj |
| wartość dodana | podaj korzyść i jej podstawę |
| dedykowane rozwiązanie | opisz, co zostało dostosowane |

Nazwa produktu, dosłowny cytat i termin wymagany przez odbiorcę mogą zostać.
W pozostałych przypadkach wybierz polskie słowo pasujące do zdania.
Nie zamieniaj każdego trafienia na jeden stały synonim.

## Pozostałe sygnały do sprawdzenia

| Sygnał | Przeredaguj tak |
| --- | --- |
| „W dzisiejszych czasach”, „W dobie” | Zacznij od aktualnego faktu albo problemu. |
| „Warto zauważyć, że”, „Należy podkreślić, że” | Podaj to, co warto zauważyć. |
| „Nie jest tajemnicą, że”, „Co ciekawe” | Zapisz samą informację. |
| „To kluczowe”, „I to zmienia wszystko” | Pokaż potwierdzony skutek. |
| „Nie sposób przecenić” | Podaj skalę tylko wtedy, gdy masz dowód. |
| „Potencjał jest ogromny”, „To dopiero początek” | Zakończ na ostatnim ustaleniu. |
| „Przyszłość należy do…” | Opisz obecny kierunek bez przepowiedni. |
| „Niezwykle”, „zdecydowanie”, „absolutnie” | Usuń, jeśli nie zmieniają sensu. |
| „Naprawdę”, „po prostu”, „tak naprawdę” | Usuń, jeśli tylko podbijają ton. |
| „De facto”, „innymi słowy” | Napisz zdanie raz, jasno. |
| „Zostało wdrożone” | Nazwij wykonawcę, jeśli źródło go podaje. |
| „Dane pokazują”, „technologia umożliwia” | Nazwij wynik i warunki jego uzyskania. |
| „Wierzcie mi”, „Będę z Wami szczery” | Oprzyj zdanie na dowodzie albo własnej relacji ze źródła. |
| „Jako ktoś, kto…” | Opisz rzeczywiste doświadczenie, jeśli zostało potwierdzone. |

## Interpunkcja

W polskiej prozie nie używaj pauzy typograficznej „—” ani półpauzy „–”.
Zamień je na kropkę, przecinek lub dwukropek, albo przebuduj zdanie.
Zakres zapisz łącznikiem lub słowem „do”: „3-5 dni”, „od 3 do 5 dni”.
Po redakcji sprawdź tekst pod kątem obu znaków.

## Przykłady ilustracyjne

Poniższe sytuacje i firmy są wymyślone.
Pokazują redakcję zdań, nie stanowią twierdzeń do publikacji.

**Przed:** „W dzisiejszych czasach nasze kompleksowe rozwiązanie zapewnia wartość dodaną małym piekarniom.”

**Po:** „Przykładowa piekarnia wpisuje zamówienia do jednego kalendarza. Pracownicy widzą w nim, co trzeba upiec następnego dnia.”

**Przed:** „Warto zauważyć, że nowy terminarz to dopiero początek. To kluczowe dla rozwoju salonu.”

**Po:** „W przykładowym salonie recepcja zapisuje wizyty w terminarzu. Na koniec dnia sprawdza w nim jutrzejszy grafik.”

## Kontrola skanerem

Uruchom `audit_copy.py tekst.md --language pl`.
Skaner zgłasza rozpoznawalne frazy jako ostrzeżenia `polish-tell`.
Opcja `--strict` nadaje ostrzeżeniom kod wyjścia 1.
Trafienie wymaga oceny zdania; skaner nie przepisuje tekstu.
Struktury całego tekstu, prawdziwość twierdzeń i głos marki oceniaj ręcznie.
Własne zakazane frazy i wzorce marki nadal należą do profilu.
